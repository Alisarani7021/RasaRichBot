# تست‌ها — Tests

تست‌ها **بدون هیچ وابستگی بیرونی، بدون شبکه و بدون توکن واقعی** اجرا می‌شوند: هر تست خودش تلگرام و KV را ماسک می‌کند و مسیرهای واقعی وورکر را صدا می‌زند.

```bash
npm test                          # همه‌ی مجموعه‌ها
node tests/run.mjs worker/index.js   # یا با مسیر دلخواه فایل وورکر
```

## چه چیزی پوشش داده می‌شود

| مجموعه | چه چیزی را تضمین می‌کند |
| --- | --- |
| `interactive_api_test` | نظرسنجی زنده، پست سه‌حالته، اسلایدشو، پایان رأی‌گیری، فهرست مینی‌اپ، مسیر کانال (انتشار «در پاسخ»، جایگزینی، حفاظت ضد اسباب‌کشی) |
| `studio_picks_test` | پروتکل انتخاب اموجی (بدون تگ خام در متن، آرت دقیق انتخاب‌شده) |
| `carousel_test` | کاروسل زنده و دکمه‌های ریچ داخل پیام |
| `wave2_test` | رسانه، رندر غنی، صفحهٔ فرود |
| `live_tick_test` | استریمر و به‌روزرسانی زمان‌بندی‌شده |
| `live_post_test` | چرخهٔ عمر پست زنده و امضا |
| `emoji_packs_test` | رجیستری اموجی پرمیوم و پک‌ها |
| `channel_connect_test` | اتصال کانال، بررسی دسترسی و پیام‌ها |
| `media_edit_test` | ویرایش رسانه بدون شکستن کلیدها |

## قاعده‌ها

- هر مجموعه مستقل است و باید تنها هم سبز شود.
- خروجی غیرصفر = شکست؛ رانر همین را ملاک می‌گذارد.
- هیچ تستی نباید به اینترنت یا سرویس واقعی تلگرام وصل شود.
- برای رفتار تازه، یک `check()` جدید اضافه کن — نه اینکه تست قبلی را شل کنی.
