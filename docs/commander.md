# 🎛 فرمانده (Commander) — چت با ربات = اجرا در کانال

> مالک در پیوی ربات **تایپ می‌کند یا ویس می‌فرستد**؛ مغز هوش مصنوعی تصمیم می‌گیرد کدام ابزار را صدا بزند و رِسا کار را **واقعاً** انجام می‌دهد: عکس می‌سازد، پست منتشر می‌کند، آمار می‌دهد، لینک می‌خواند، پاک می‌کند، نظرسنجی می‌گذارد.

## استفاده
```
یه عکس از غروب تهران بساز و با یه کپشن قشنگ بذار تو کانال
آمار دیروز کانالم چطور بود؟
مناسبت فردا چیه؟ اگه خاصه یه پست تبریک بساز
این لینک رو بخون و سه نکته‌شو بذار تو کانال: https://…
یک نظرسنجی بذار: موضوع پست بعدی چی باشه؟ طلا / کریپتو / تکنولوژی
فردا صبح ۷ این متن رو بذار: …
آخرین پستی که گذاشتی رو پاک کن
کانال پیش‌فرض رو کن @mychannel
```
- **ویس**: بفرست؛ رونویسی می‌شود، انجام می‌شود و در پاسخ می‌بینی «🗣 شنیدم: …».
- هر ابزار که اجرا می‌شود، یک پیام کوتاه «🛠 …» در چت می‌آید و آخرش نتیجه + لینک.

## ابزارها (v1)
| ابزار | کار |
|---|---|
| `make_image {prompt}` | ساخت عکس (Workers AI — flux) + پیش‌نمایش در چت |
| `publish_post {text, with_image}` | انتشار در کانال (ریچ؛ با عکس آخرین ساخته‌شده) |
| `get_stats {}` | آمار واقعی: پست‌های دیروز/پریروز، بازدیدها، پست‌های برتر |
| `get_occasions {}` | مناسبت امروز/فردا (شمسی) + تعطیلی (primary از فهرست رسمی) |
| `web_fetch {url}` | خواندن متن یک صفحه (برای خلاصه‌کردن لینک) |
| `poll {question, options}` | نظرسنجی در کانال |
| `schedule_post {text, in_minutes}` | انتشار در آینده (۱ تا ۱۰۰۸۰ دقیقه) |
| `delete_last {}` | حذف آخرین پستِ گذاشته‌شده |
| `set_channel {channel}` | کانال پیش‌فرض |

## مغز
سه مسیر، به ترتیب اولویت:
1. **Workers AI داخل ورکر** (پیش‌فرض تولید): بایندینگ `AI` — بدون کلید، رایگان (سهمیهٔ روزانهٔ حساب).
   - مدل متن: `@cf/meta/llama-3.3-70b-instruct-fp8-fast` · عکس: `@cf/black-forest-labs/flux-1-schnell` · ویس: `@cf/openai/whisper`
2. **دروازهٔ تستی** `CMDR_BRAIN_URL` (فقط برای تست محلی روی کامپیوتر).
3. **کلید جمنای** `GEMINI_API_KEY` (اختیاری؛ اگر پروژهٔ جمنای در دسترس شد، خودکار استفاده می‌شود).

## راه‌اندازی در دیپلوی
بایندینگ‌های لازم در `deploy_metadata.json`:
```json
{ "name": "AI", "type": "ai" },
{ "name": "COMMANDER_ON", "type": "plain_text", "text": "1" }
```
- `COMMANDER_ON=0` → فرمانده خاموش می‌شود (تست‌های خودکار هم پیش‌فرض خاموش‌اند).
- `COMMANDER_OWNERS="123,456"` → فقط این آی‌دی‌ها فرمانده را فعال کنند (پیش‌فرض: مالک + ادمین).
- `CMDR_TEXT_MODEL` / `CMDR_IMAGE_MODEL` / `CMDR_STT_MODEL` → تغییر مدل‌ها.

## تست محلی
```bash
# با دروازهٔ تستی (ورکر آزمایشی rasa-aitest):
CMDR_BRAIN_URL=https://rasa-aitest.4lisarani-1.workers.dev CMDR_BRAIN_KEY=… node tools/commander-e2e.mjs all
```
سناریوها: عکس+انتشار، آمار، مناسبت+تبریک، پیام صوتی، خواندن لینک، حذف آخرین پست.

## نکته‌های امنیتی
- فقط آی‌دی‌های فهرست‌شده پاسخ می‌گیرند؛ بقیهٔ کاربران دسترسی ندارند.
- انتشار مستقیم است (به‌خواست مالک)؛ برای بازنویسی/حذف هم ابزار دارد.
- «متن/آمار جعلی» در پرامپت ممنوع شده و مناسبت‌ها فقط از فهرست رسمی برداشته می‌شوند.
