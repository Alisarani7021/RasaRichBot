> 🎓 **تازه‌کار هستی؟** نسخهٔ مو‌به‌موی این راهنما (با کلیک‌به‌کلیک و خطاهای رایج): `docs/gemini-mo-bemo.md` — فایل پل: `https://paste.rs/hczO4`

> دو مسیر: **الف) فقط با گوشی، همین حالا** · **ب) با کامپیوتر، قدرت کامل (MCP)**

## الف) فقط با گوشی — از همین الان کار می‌کند ✅

### ۱. Gem را فقط از «وب» بساز (اپ موبایل نمی‌سازد)
اپ موبایل وقتی وارد تب Your Gems می‌شوی می‌نویسد: «You can create Gems on the web here» — این طبیعی است:
**ساخت/ویرایش Gem فقط در وب است، ولی بعد از ساخت، در اپ موبایل هم می‌آید.**

1. در کروم گوشی همان بنر را بزن (یا `gemini.google.com` را باز کن) و با حساب Pro خودت وارد شو.
2. منوی ☰ → **Gems / Explore Gems** → دکمه **New Gem**.
3. **Name**: «نویسندهٔ کانال» (یا هر چه دوست داری).
4. **Instructions**: متن پایین را کامل پیست کن و وسطش `<موضوع کانال>` را با موضوع خودت عوض کن.
5. (اختیاری) در بخش **Knowledge** چند نمونه پست خوب خودت را آپلود کن تا لحن را یاد بگیرد.
6. **Save** → حالا در اپ موبایل → Gems → تب **Your Gems** ظاهر می‌شود و از همان‌جا چت می‌کنی.

**متن دستور Gem (کامل کپی کن):**
```
تو نویسندهٔ پست کانال تلگرامی من هستی. قواعد:
• فارسی محاوره‌ایِ تمیز، بدون غلط، حداکثر ۳ ایموجی در هر پست.
• خروجی را همیشه در قالب مارک‌داون بده: تیتر با ##، بولت با -، تأکید با **.
• ساختار: قلاب در خط اول، سه تا پنج بند کوتاه، یک جمع‌بندی یا سؤال در آخر.
• طول بین ۵۰۰ تا ۹۰۰ کاراکتر.
• هیچ هشتگ و لینک اضافه‌ای اضافه نکن مگر بگویم.
• ته هر پاسخ، در یک خط جدا، سه «تیتر جانشین» بده با برچسب تیتر۲/تیر۳.
• هرگز آمار یا خبر جعلی نساز؛ اگر منبعی ندادم، مشخص کن که عمومی و غیرقطعی است.
موضوع این کانال: <موضوع کانال>   |   مخاطب: <مخاطب هدف>
```

### ۱.۵ ⚠️ صداقت مهم: Gem به رِسا «وصل» نمی‌شود
Gem فقط یک دستور متنی است — به هیچ ابزار بیرونی (رِسا، MCP، انتشار خودکار) وصل نمی‌شود.
با Gem فقط **متن** می‌گیری؛ انتشار همچنان در مینی‌اپ رِسا است (پیست → آپلود کاور → انتشار).
**اتصال واقعی (مثل MCP کلاد) فقط با بخش «ب» یعنی Gemini CLI روی کامپیوتر ممکن است.**

### ۱.۶ 🎁 بونوس موبایل: Scheduled actions
در اپ Gemini → پروفایل → **Scheduled actions** می‌توانی یک پرامپت زمان‌بندی‌شده بسازی؛ مثلاً هر روز ۷:۰۰ صبح:
«یک پست صبحگاهی دلگرم‌کننده برای کانالم بنویس (حداکثر ۴۰۰ کاراکتر، با یک کار کوچک برای امروز).»
نتیجه سر ساعت می‌آید و تو فقط پیست و منتشر می‌کنی. (بعد از دیپلوی b40، این کار را خودِ رِسا خودکار داخل کانال انجام می‌دهد.)

### ۲. سه پرامپت آماده (کپی کن، هر روز استفاده کن)

**پست خبری/تحلیلی:**
```
یک پست کانال دربارهٔ «<موضوع>» بنویس. منبع: <لینک یا متن>. لحن: تحلیل‌شده و بی‌طرف.
```

**پست دلگرم‌کننده برای صبح:**
```
یک پیام صبحگاهی دوستانه و دلگرم‌کننده برای اعضای کانالم بنویس (حداکثر ۴۰۰ کاراکتر)
که با یک «کار کوچک امروز» تمام شود.
```

**کاریکاتور/کاور برای پست:**
```
برای این متن، یک تصویر کاور ۱۶:۹ بساز: مینیمال، تیره، با فضای خالی برای متن.
بدون ایموجی و بدون نوشتهٔ اضافه. متن: <متن پست>
```
تصویر را ذخیره کن → در مینی‌اپ رِسا **آپلود** کن (بخش رسانه) → در پست بگذار.

### ۳. گردش کار روزانه‌ات با گوشی (۲ دقیقه)
1. در Gem بگو موضوع را → پست آماده بگیر (مارک‌داون + سه تیتر جانشین).
2. در Gem بگو «کاور همین پست» → تصویر را ذخیره کن.
3. مینی‌اپ رِسا → پیست متن (رِسا خودش مارک‌داون را به ریچ تبدیل می‌کند و اموجی پرمیوم می‌گذارد) → آپلود کاور → انتشار (با امضا یا بدون امضا).

> 💡 مناسبت‌های روز را هم از رِسا بگیر: در پیوی ربات بنویس «مناسبت امروز» (یا هر روز صبح، پستِ صبح کانال خودش می‌آید).

## ب) با کامپیوتر — جمنای + MCP (قدرت کامل) 🚀

با این کار، جمنای **خودش** ابزارهای رِسا را صدا می‌زند: آمار بگیرد، پست رندر کند، منتشر کند.

### گام ۱ — نصب
```bash
# Node 20+ لازم است → از nodejs.org نصب کن
npm install -g @google/gemini-cli      # یا:  npx @google/gemini-cli
gemini                                  # ورود با حساب گوگل (همان حساب اشتراک AI Pro)
```
اگر نوشت «Free tier» با اینکه Pro داری: به `aistudio.google.com/apikey` برو و **همهٔ کلیدهای API را پاک کن** (اگر کلید AI Studio بماند، CLI وضعیت پلن رایگان را ترجیح می‌دهد)، بعد دوباره logout/login کن.
> با پلن Pro: تا **۱٬۵۰۰ درخواست در روز**.

### گام ۲ — توکن ربات را امن بگذار
```bash
mkdir -p ~/.rasa && printf '%s' 'BOT_TOKEN_اینجا' > ~/.rasa/bot_token && chmod 600 ~/.rasa/bot_token
```

### گام ۳ — پل رِسا را وصل کن
فایل `rasa-mcp.mjs` را از مخزن بردار (`tools/rasa-mcp.mjs`) و جایی بگذار؛ مثلاً `~/rasa/rasa-mcp.mjs`.

**راه الف — دستور (پیشنهادی):** دقت کن `-s user` بگذاری، وگرنه فقط برای همان پوشه ثبت می‌شود:
```bash
gemini mcp add -s user -e RASA_UID=8795596928 -e RASA_BOT_TOKEN=توکن_ربات rasa node ~/rasa/rasa-mcp.mjs
gemini mcp list        # باید rasa را Connected نشان دهد
```
(اگر می‌خواهی توکن داخل settings.json نباشد، `-e` را نده و به‌جایش فایل `~/.rasa/bot_token` را بساز.)

**راه ب — فایل تنظیمات** (`~/.gemini/settings.json`) — ویندوز: `%USERPROFILE%\.gemini\settings.json`:
```json
{
  "mcpServers": {
    "rasa": {
      "command": "node",
      "args": ["C:/rasa/rasa-mcp.mjs"],
      "env": { "RASA_UID": "8795596928" },
      "trust": true,
      "timeout": 60000
    }
  }
}
```

> نکتهٔ پلن: اگر CLI نوشت «Free tier» با اینکه Pro داری، به `aistudio.google.com/apikey` برو و **کلیدهای AI Studio را پاک کن**، بعد دوباره login کن.

### گام ۴ — از داخل جمنای بگو، انجام می‌شود
```
آمار کانالم را بگو                            → get_stats
مناسبت امروز و فردا چیه؟                      → get_occasions
برای مهرگان یک پست بنویس و پیش‌نمایش بده        → render_draft / preview_daily
همین پست را در کانال منتشر کن                  → publish_post
پست صبح امروز را بفرست                         → publish_daily
```

**کلود هم همین را دارد:**
```bash
claude mcp add rasa -- node /path/to/rasa-mcp.mjs
```

### تست بدون کلاینت (خط فرمان):
```bash
node tools/rasa-mcp.mjs cli stats @mychannel
node tools/rasa-mcp.mjs cli occasions
node tools/rasa-mcp.mjs cli daily morning --channel @mychannel
node tools/rasa-mcp.mjs cli post --channel @mychannel --text "سلام از رِسا"
```

## ابزارهای فعلی پل (۷ عدد)
| ابزار | کار |
|---|---|
| `list_channels` | کانال‌های وصل‌شده + تعداد پیش‌نویس/قالب |
| `get_stats` | آمار واقعی: دیروز، بازدید، پست‌های برتر، آخرین پست‌ها |
| `get_occasions` | مناسبت امروز و فردا (شمسی) + تعطیلی |
| `render_draft` | متن → ریچ تلگرام + اموجی پرمیوم (بدون انتشار) |
| `preview_daily` | پیش‌نمایش «صبح کانال»/«خلاصهٔ روز» با دادهٔ واقعی |
| `publish_post` | انتشار در کانال (با گزینهٔ «بدون امضا = ۱ اعتبار») |
| `publish_daily` | انتشار واقعی پست روزانه |

### 🐧 فقط گوشی داری؟ (Termux)
همین کار روی خودِ اندروید هم شدنی است: **Termux** را از F-Droid نصب کن، بعد:
```bash
pkg update && pkg install nodejs-lts
npm i -g @google/gemini-cli
termux-setup-storage                     # دسترسی به حافظه برای فایل پل
# rasa-mcp.mjs را در ~ بگذار، توکن را در ~/.rasa/bot_token
gemini mcp add -s user -e RASA_UID=8795596928 rasa node ~/rasa-mcp.mjs
gemini                                   # /mcp → باید rasa و ابزارهایش را ببینی
```
اگر خواستی، همین مسیر را قدم‌به‌قدم برایت جلو می‌بریم.

## بعد از دیپلوی نسخهٔ بعدی ورکر (b40) چه چیزی اضافه می‌شود؟
- **زمان‌بندی از داخل جمنای**: «فردا ۷ صبح منتشر کن» (ابزار `schedule_post`).
- **صبح کانال و خلاصهٔ روز روی cron خود ورکر** (بدون نیاز به کامپیوتر روشن).
- بعد از آن: MCP روی خودِ ورکر → **از هر جا، حتی بدون کامپیوتر** وصل می‌شوی.

## امنیت
- فایل توکن = قدرت کامل ربات؛ `chmod 600` و هیچ‌جا آپلود نکن.
- پیشنهاد: یک ربات دوم بسازیم و آن را ادمین کانال کنی؛ توکنِ ربات اصلی دستِ ابزار بیرونی نیفتد.
- هر فراخوانی ابزار در پیوی خودت لاگ می‌شود (در نسخهٔ ورکری).

> وضعیت: پلِ MCP ساخته و **تست زنده** شد — پست آزمایشی از مسیر MCP در کانال منتشر و بعد پاک شد.
