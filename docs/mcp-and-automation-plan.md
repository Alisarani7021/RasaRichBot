## ۱) 🔌 رِسا به‌عنوان MCP Server (ابزار برای کلاد، جمنای، کرسر، VS Code)

**یعنی چه؟** رِسا یک آدرس MCP می‌دهد و هر کلاینت هوش مصنوعی می‌تواند ابزارهایش را صدا بزند.
تو در **Claude Code / Claude Desktop / Gemini CLI / Cursor / VS Code / ChatGPT Desktop** فقط حرف می‌زنی؛ خود کلاینت ابزار را اجرا می‌کند:

```
«برای کانالم یه پست دربارهٔ مهرگان بنویس و ساعت ۸ منتشر کن»
     └─→ rасa.get_occasions(today)      // مناسبت‌های روز
     └─→ rasa.render_draft(text)        // رندر ریچ + اموجی پرمیوم
     └─→ rasa.publish(channel, at=08:00)
```

### ابزارهای فاز اول (۶ عدد)
| ابزار | کار |
|---|---|
| `list_channels` | فهرست کانال‌های وصل‌شده + وضعیت دسترسی |
| `get_stats` | بازدید پست‌های دیروز/هفته، اعضا، سه پست برتر |
| `get_occasions` | مناسبت امروز/فردا (تقویم هجری شمسی) |
| `render_draft` | متن → HTML ریچ + نقشهٔ اموجی پرمیوم (بدون انتشار) |
| `publish_post` | انتشار/زمان‌بندی در کانال (با تأیید اجباری برای کانال‌های حساس) |
| `schedule_post` | صف انتشار با قواعد (فاصلهٔ حداقل، ساعت مجاز) |

### معماری
- MCP روی **Streamable HTTP** (همان ورکر ورکری که داریم) — بدون سرور جدید.
- احراز هویت: توکن اختصاصی برای هر کلاینت (Bearer) + دامنهٔ مجاز.
- هر فراخوانی: لاگ کامل در PV خودت («چه کلاینتی چه کاری کرد»).
- مسیرها (پیشنهادی): `/mcp` (اتصال)، `/mcp/tools` (فهرست)، صفحهٔ توکن در پیوی.

### چرا با گیت‌هاب/کلاد جوش می‌خورد
- **Gemini CLI** پشتیبانی MCP دارد → با اشتراک Pro (۱٬۵۰۰ درخواست/روز) از ترمینال، کانال را می‌چرخانی.
- **Claude Code** همان الگو را با `claude mcp add rasa` می‌گیرد.
- هر ابزار قابل تست دستی با curl است، پس دموی زنده سریع می‌شود.

## ۵) 🧩 نود آمادهٔ n8n / Make / Zapier (+ وبهوک رویداد)

**یعنی چه؟** بدون یک خط کد، هر برنامه‌ای به رِسا وصل می‌شود؛ دو طرفه:

### الف) ورودی — «برنامه‌ها برای رِسا کار می‌کنند»
| منبع | نتیجه روی کانال |
|---|---|
| RSS (ایسنا، خبرآنلاین، آپارات) | پست خودکار با منبع |
| Google Sheets / Notion / Airtable | ردیف «آماده» → انتشار |
| GitHub (PR merge) | پست انتشار + لینک |
| Gmail / Outlook | ایمیل منتخب → پست |
| نوبیتکس/بورس/قیمت طلا | هشدار آستانه‌ای |
| فرم ثبت‌نام سایت | پست «عضو جدید/افتخار» |

### ب) خروجی — «رِسا به برنامه‌ها خبر می‌دهد» (وبهوک رویداد)
رویدادهای امضاشده با HMAC-SHA256 (+`X-Rasa-Signature`):
`post.published` • `poll.closed` • `member.joined` • `comment.flagged` • `views.milestone` • `daily.sent`

مخاطب‌ها: **n8n / Make / Zapier / Google Apps Script / سرور خودت / Slack / Discord**.

### معماری
- جدول اشتراک وبهوک: `hook:<uid>:<id>` = {url, events, secret, on}
- صف بازفرست با retry نمایی (3 تلاش، backoff 1s/10s/60s) و غیرفعال‌سازی خودکار در ۴۰۱/۴۰۴.
- «تست وبهوک» با یک دکمه در مینیاپ + نمایش پاسخ آخرین ۵ فراخوانی.

## 🤝 چرا این دو کنار هم؟
- **MCP** = رِسا ابزار می‌دهد به کلاینت‌های هوش مصنوعی (تو حرف می‌زنی).
- **n8n/Zapier** = رِسا رویداد می‌دهد و رویداد می‌گیرد (برنامه‌ها کار می‌کنند).
- **وبهوک** ستون مشترک هر دو است؛ پس اول ساخته شود، هر دو ایده سریع‌تر می‌رسند.

## 🎁 جمنای — از اشتراک ۱۸ماهه چطور استفاده کنیم؟
1. **اشتراک مصرفی ≠ API**: Google AI Pro به‌خودی‌خود کلید API نمی‌دهد؛ ولی از **۲۷ ژانویه ۲۰۲۶** بخشی از مزایای Developer Program Premium (اعتبار Google Cloud) داخل AI Pro/Ultra آمده و **همان اعتبار را می‌شود برای Gemini API خرج کرد**.
2. **Gemini CLI بدون کلید** (ورود با حساب گوگل): در پلن Pro تا **۱٬۵۰۰ درخواست در روز** — و **MCP** را پشتیبانی می‌کند → دقیقاً درایور ایدهٔ ۱.
3. **AI Studio Free**: فِلش آزاد + ۲.۵ Pro روزی ۱۰۰ درخواست — برای کارهای روزانهٔ رِسا کافی است.
4. **تصویر (Nano Banana)**: در اپ جمنای رایگان (سقف محاسباتی)، در API پرداختی (~۰٫۰۲–۰٫۰۹ دلار بر تصویر). برای کارت‌های کانال: اول رندر SVG خودمان، در صورت نیاز تصویر جمنای با همان اعتبار Cloud.

## ⚙️ ترتیب ساخت پیشنهادی
