# ⚡ نسخهٔ اختصاصی رِسا — b48 (۱ اکتبر)

> سه تذکر تو اعمال شد: **بدون توکن ربات** · **داخل مینی‌اپ** · **بدون پوش به گیت‌هاب**

---

## ۱) چرا دیگر توکن ربات نمی‌خواهد؟
چون **رِسا همان یک ربات است**. کسی ربات تازه نمی‌سازد. مدل کار:

```
تو  ──►  مینی‌اپ رِسا  ──►  «نسخهٔ اختصاصی»
                                │  فقط توکن کلادفلر (سهمیهٔ خودت)
                                ▼
                    ورکر شخصی روی حساب خودت
                    ├─ هوش مصنوعی و ابزارها: با سهمیهٔ خودت
                    └─ انتشار در کانال: از طریق «پل» رِسا (همان ربات)
```

- **ربات رسا** = دروازهٔ همه؛ کانال‌ها همان‌جا وصل‌اند، پست‌ها همان‌جا منتشر می‌شوند.
- **ورکر شخصی** = فقط مغز و ابزار؛ روی حساب خودت، با سهمیهٔ خودت.
- «پل»: ورکر شخصی هر کار تلگرامی را به رسا می‌فرستد و رسا با همان ربات انجام می‌دهد.
  - اگر ورکر روی **حساب خودم** باشد → اتصال داخلی (Service Binding).
  - اگر روی **حساب خودت** باشد → مسیر امن HTTPS + کلید یک‌بارمصرف.

## ۲) کجاست؟
**داخل مینی‌اپ**: ربات رسا → دکمهٔ ☰ (منو) → **«⚡ نسخهٔ اختصاصی»**
یا: `https://rich-post-bot.4lisarani-1.workers.dev/go` → خودش می‌رود به همان بخش.

## ۳) سه قدم (همه در یک صفحه)
1. **🔑 ساخت توکن آماده در کلادفلر** (صفحه با دسترسی‌های درست از قبل پر می‌شود → Continue to summary → Create Token → کپی)
2. توکن را بچسبان، کانالت را بنویس (اختیاری)، تیک موافقت
3. **🚀 نصب کن** → چند ثانیه بعد: لینک شخصی MCP + راهنمای اتصال جمنای/کلاد/گروک

## ۴) بعد از نصب چه داری؟
| چیز | یعنی چه |
|---|---|
| 🔗 لینک شخصی MCP | `https://<نام‌تو>.<حساب‌تو>.workers.dev/api/mcp/<کلید>` — به جمنای/کلاد/گروک وصلش کن |
| 🧠 سهمیهٔ خودت | هوش مصنوعی و ابزارها روی حساب خودت اجرا می‌شوند؛ سهمیهٔ من دست نمی‌خورد |
| 🤖 همان ربات رسا | برای کاربر و کانال، همه‌چیز از ربات رسا انجام می‌شود |
| 📣 کانال | اگر در فرم داده باشی، همان لحظه برایت ثبت می‌شود؛ وگرنه در رسا بگو: `/channel @mychannel` |

## ۵) صادقانه
- گروک برای MCP فقط **حساب پرداختی**؛ جمنای و کلاد آزاد.
- سهمیهٔ هوش مصنوعی **هر حساب سر جای خودش** است؛ با پلن ۵ دلاری `Workers Paid` سقف روزانه برداشته می‌شود.
- توکن‌ها **هیچ‌جا ذخیره نمی‌شوند** (فقط همان لحظه برای ساخت ورکر).
- محدودیت ۶ نصب در ساعت (ضد سوءاستفاده).
- رسانه (عکس/ویدیو) در پیوی **رسا** فرستاده می‌شود؛ ورکر شخصی متنی منتشر می‌کند.

## ۶) برای من (یادداشت فنی)
- مهر نسخه: `SP_BUILD='b48'` — قبل از هر تغییر نصب، یکی جلو ببر.
- فایل ربات به مستأجر از **KV خودمان** (`asset:bundle`) داده می‌شود؛ گیت‌هاب فقط پشتیبان است. → نصب‌ها به پوش گیت‌هاب وابسته نیستند.
- مینی‌اپ: `asset:app.html` (بخش `#dedicated` + `paintDedicated()` + ناوبری منو).
- مسیرها: `POST /api/selfinstall` (فقط با `initData` امضاشدهٔ تلگرام) · `POST /api/bridge` · `GET /bundle.js` · `GET /go → /app#dedicated`.
- کلید پل و کانال هر کاربر در KV رسا: `bridge:<key>` و `cmd:chan:<uid>` · دفتر نصب: `installs`.
- تست‌ها: `mcp 15` · `sp 26` · `sp2 27` · `install 29` · `manner 13` — همه سبز. بازسازی: `bash cf/patch/rebuild.sh` · دیپلوی: `bash cf/patch/deploy.sh`.
- e2e واقعی انجام‌شده و پاک‌شده: نصب → ۵۸ ابزار → `get_stats` روی کانال واقعی از پل → انتشار `t.me/xjjsjsjsjji/119` و حذف فوری → حذف ورکر + ۱۲ انبار + ۳ کلید پل.
- **هیچ‌چیز روی گیت‌هاب پوش نشده** — تا نگویی، پوش نمی‌کنم.
