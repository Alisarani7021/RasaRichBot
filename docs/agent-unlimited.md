# ∞ قدرت‌های نامحدود (b44) — گیت‌هاب، میزبانی HTML، اپ هوشمند، کد، ابزار تازه

> همهٔ این‌ها **همین حالا زنده** است: در جمنای، در کلاد، و در چت/ویس خود ربات. مجموع ابزارها: **۵۷ ثابت + هر تعداد که خودت بسازی**.

## ۱) رصد گیت‌هاب — «هر چیزی منتشر شد، خودکار اعلام کن»
بر پایهٔ فیدهای رسمی گیت‌هاب (بدون نیاز به توکن، برای مخزن‌های عمومی):

| ابزار | کار |
|---|---|
| `github_watch {repo, kind, every_minutes, post, translate}` | افزودن رصد. `kind`: `commits` \| `releases` \| `tags` \| `issues` \| `stars` — `post:true` یعنی تازه‌ها در کانال هم منتشر شود؛ `translate:true` تیتر انگلیسی را فارسی می‌کند |
| `github_check {repo, kind}` | همین حالا آخرین موارد را بگیر (بدون انتظار) |
| `github_list` / `github_remove {id}` | مدیریت رصدها |

- بار اول «ساکت» است (فقط وضعیت فعلی را ثبت می‌کند) تا چیزهای قدیمی را پست نکند؛ از آن به بعد فقط **تازه‌ها**.
- «ستاره» از خود صفحهٔ گیت‌هاب خوانده می‌شود (API گیت‌هاب از کلادفلر محدود می‌شود).

### رصد تکیِ ایشو
`issue_watch {url}` → کامنت تازه، بسته/باز شدن، تغییر عنوان یا برچسب را خبر می‌دهد. اگر API محدود باشد، از فید اتمیک استفاده می‌کند. مدیریت: `issue_list` / `issue_remove {id}`.

## ۲) ساخت و میزبانی HTML — روی دامنهٔ خودت، بدون سرور
| ابزار | کار |
|---|---|
| `make_page {title, prompt, agent}` | یک صفحهٔ HTML فارسی می‌سازد و زنده میزبانی می‌کند → `/s/<مالک>/<slug>` |
| `make_app {name, goal}` | **اپ هوشمند**: صفحه + نقطهٔ پایانی `./api` که سرِ درخواست از مغز جواب می‌گیرد |
| `site_create` / `site_add_file {slug, path, content}` | پروژهٔ چندصفحه‌ای؛ فایل‌ها را دقیق خودت می‌نویسی (index.html، style.css، script.js، SVG…) |
| `page_list` / `page_delete` / `app_delete` | مدیریت |

- همه‌چیز موبایل‌فرست، RTL و بدون منبع بیرونی (چون پیش‌نمایش هم بدون اینترنت کار می‌کند).
- آدرس ریشهٔ صفحه‌ها: `/s/<شمارهٔ مالک>/` — فهرست همهٔ صفحه‌ها و اپ‌ها.
- ابزار `make_page` با `agent:true` صفحهٔ پرسش‌وپاسخ زنده می‌سازد.

## ۳) کدنویسی
`make_code {name, prompt}` → کد می‌نویسد، فایل را در پیوی مالک می‌فرستد و لینک زندهٔ `/w/<مالک>/<نام>` می‌دهد. `code_list` / `code_get {name}` برای مدیریت.

## ۴) ابزار تازه در یک لحظه (قلبِ «نامحدود»)
`api_tool_add {name, url, method, headers, body, desc}` → هر وب‌سرویس https را به ابزار جدید ربات تبدیل می‌کند؛ **بدون دیپلوی**. از آن لحظه در فهرست ابزارهای جمنای/کلاد ظاهر می‌شود و با `api_<name>` صدا زده می‌شود. در آدرس/بدنه از `{پارامتر}` استفاده کن.
نمونهٔ زنده: `api_weather` (هوای زنده از open-meteo) — و کاربر واقعی? همین حالا امتحان کن.

## ۵) اتصال ورسل (Vercel)
ورکر خودمان صفحات را میزبانی می‌کند؛ برای **استقرار روی ورسل** از MCP رسمی ورسل استفاده کن:

**کلاد (Claude)** — Settings → Connectors → Add custom connector:
- Name: `Vercel` · URL: `https://mcp.vercel.com`
- بعد Sign in و در منوی ابزارها فعالش کن. (در کلاد کد: `claude mcp add --transport http vercel https://mcp.vercel.com`)

**جمنای (Gemini)** — Settings → Connected Apps → Custom apps for Spark → Add:
- URL: `https://mcp.vercel.com` · Client ID/Secret: خالی · تأیید و ذخیره.

با این، کلاد/جمنای پروژه‌ها، دیپلوی‌ها، لاگ‌ها و آنالیتیکس ورسل تو را مستقیم می‌بینند و مدیریت می‌کنند.

## صادقانه — مرزها
- **اجرای کد دلخواه داخل ورکر** ممکن نیست (کلادفلر eval را بسته). اما `api_tool_add` تقریباً همان کار را می‌کند: هر سرویس بیرونی → ابزار تازه.
- **API گیت‌هاب از کلادفلر** سقف IP می‌خورد (۴۰۳). راه‌حل: فیدهای اتمیک (که استفاده می‌کنیم) و در آینده توکن گیت‌هاب به‌عنوان Secret.
- **ویدیوسازی خودکار / تحلیل عکس ورودی**: روی این حساب نه. (ویدیو را در جمنای بساز، برای ربات بفرست → منتشر می‌شود.)
