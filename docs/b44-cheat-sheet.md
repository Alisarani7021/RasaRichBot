# ∞ رسا نامحدود شد — b44 (زنده: ۱ اکتبر)

حالا **۵۷ ابزار** داری — و مهم‌تر: می‌توانی خودت بی‌نهایت ابزار اضافه کنی. این‌ها همه از جمنای، کلاد و چت/ویس کار می‌کنند.

---

## ۱) گیت‌هاب زیر نظر — «هر چیزی منتشر شد، خودکار اعلام کن»
بگو:
```
مخزن Alisarani7021/RasaRichBot را زیر نظر بگیر؛ هر کامیت تازه که آمد در کانال هم بذار
```
- نوع رصد: `commits` (کامیت‌ها) · `releases` (ریلیزها) · `tags` (تگ‌ها) · `issues` (ایشوها) · `stars` (ستاره‌ها)
- «ترجمه کن» → تیتر انگلیسی خودکار فارسی می‌شود.
- «اول ببینم» → با `post:false` فقط در پیوی خودت خبر می‌دهد.
- یک ایشوی خاص: «ایشو شماره ۱۲ این مخزن را رصد کن» — کامنت تازه، بسته شدن، تغییر عنوان را خبر می‌دهد.
- الان چه خبر؟ → «آخرین کامیت‌های مخزنم را بگو» (بدون انتظار می‌آورد).

## ۲) HTML می‌سازد و زنده می‌کند (روی دامنهٔ خودت)
```
یک صفحهٔ معرفی شیک برای کانالم بساز و لینکش را بده
```
- `make_page` → صفحهٔ ثابت · `make_app` → **اپ هوشمند** (سرِ هر پرسش از مغز جواب می‌گیرد)
- «این کد HTML را دقیق بذار» → `site_add_file` (index.html/css/js دلخواه تو)
- فهرست همه: `.../s/5982315292/` — نمونه‌های زندهٔ همین امروز: `/s/5982315292/hub/` و `/s/5982315292/rasa-intro` و اپ `/s/5982315292/safar/`

## ۳) کد می‌نویسد
```
یک اسکریپت پایتون بنویس که پست‌های کانالم را بر اساس بازدید مرتب کند
```
→ فایل را در پیوی خودت می‌فرستد + لینک زنده `/w/...`. (نمونهٔ زنده: `top_posts.py`)

## ۴) هر API → ابزار تازه، در یک لحظه (بدون دیپلوی)
```
ابزار تازه بساز: api_openweather — از این آدرس آب‌وهوا بگیر: https://api.open-meteo.com/...
```
→ از همان لحظه در فهرست ابزارهای جمنای و کلاد ظاهر می‌شود و با `api_<نام>` کار می‌کند. (نمونهٔ زنده: `api_weather` — هوای تهران را همین حالا گرفت.)

## ۵) ورسل را وصل کن (وقتی خواستی)
**کلاد:** Settings → Connectors → Add custom connector → URL: `https://mcp.vercel.com` → Sign in
**جمنای:** Settings → Connected Apps → Custom apps for Spark → Add → URL: `https://mcp.vercel.com` (Client ID/Secret خالی)
با این، خودشان پروژه‌ها، دیپلوی‌ها و لاگ‌های ورسل تو را مدیریت می‌کنند. (صفحه‌های خودمان هم لازم نیست ورسل داشته باشند — روی دامنهٔ خودت زنده‌اند.)
