# 🏗 نصب اختصاصی — هر کس ربات خودش (b45 · زنده)

## لینکی که به همه می‌دهی
```
https://rich-post-bot.4lisarani-1.workers.dev/go
```
هر کسی این را باز کند، **۶۰ ثانیه بعد** ورکر و ربات اختصاصی خودش را دارد: روی حساب کلادفلر خودش، با سهمیهٔ هوش مصنوعی خودش، برای کانال خودش. سهمیهٔ تو هیچ مصرف نمی‌شود.

---

## دوستت چه می‌بیند (سه قدم، همه در همان صفحه)
**۱)** دکمهٔ «🔑 ساخت توکن آماده در کلادفلر» → صفحهٔ کلادفلر با دسترسی‌های درست از قبل پر شده → `Continue to summary` → `Create Token` → کپی
**۲)** در تلگرام به `@BotFather` → `/newbot` → اسم و یوزرنیم → توکن (`123456:AAE...`) را کپی
**۳)** هر دو را در صفحه بچسباند → تیک موافقت → **نصب کن** → ۶۰ ثانیه صبر → لینک MCP اختصاصی‌اش را می‌گیرد

## کدهای راهنما برای تو (و آن‌ها) در پیوی ربات
بعد از نصب، اولین کسی که در پیوی ربات پیام بدهد **مالک خودکار** می‌شود و این‌ها کار می‌کنند:
| دستور | کار |
|---|---|
| `/start` | ثبت مالکیت + راهنمای کامل |
| `/mcp` | لینک اتصال MCP (هر وقت گم شد) |
| `/channel @mychannel` | ثبت کانال (بعد ربات را ادمین کانال کند) |
| `/help` | راهنمای سریع |

## وصل‌کردن به هوش مصنوعی‌ها
| سرویس | مسیر (لینک MCP را بچسبان) |
|---|---|
| **جمنای** | Settings → Connected Apps → Custom apps for Spark → Add → Client ID/Secret خالی → Save |
| **کلاد** | Settings → Connectors → Add custom connector → Add |
| **گروک** | grok.com/connectors → New Connector → Custom (اشتراک پرداختی) |
| کلاد کد | `claude mcp add --transport http rasa <لینک>` |

از این لحظه هر کس با هوش مصنوعی خودش، **کانال و ربات خودش** را می‌چرخاند — ۵۸ ابزار همه‌جا.

## چیزهایی که در همین نصب خودکار انجام می‌شود
✅ ساخت ورکر روی حساب خودش · ✅ ۳ انبار داده + ابزار State · ✅ بلینگ هوش مصنوعی (AI) روی حساب خودش
✅ فعال‌سازی آدرس `*.workers.dev` · ✅ تنظیم وب‌هوک رباتش · ✅ ثبت دستورهای ربات
✅ زمان‌بند هر دقیقه (پست خودکار/RSS/رصد) · ✅ ساخت لینک MCP با کلید اختصاصی
✅ مهر نسخه: نصب همیشه **تازه‌ترین** کد را از گیت‌هاب می‌گیرد

## تست واقعی که انجام دادم (۱ اکتبر)
سه نصب واقعی روی حساب خودم انجام دادم و بعد پاکشان کردم:
- ورکر ساخته شد، MCP جواب داد (۵۸ ابزار)، `market` قیمت واقعی داد (طلای ۱۸: ۲۵۴٬۹۴۰٬۰۰۰ تومان)، `github_check` آخرین کامیت‌ها را آورد، `/go` روی ورکر مستأجر ۲۰۰ داد.
- یک نکتهٔ پیدا‌شده و اصلاح‌شده: بدون کانال، قبلاً هیچ ابزاری کار نمی‌کرد → الان همه کار می‌کنند و فقط ابزارهای انتشار، پیام راهنما می‌دهند.
- یک نکتهٔ پیدا‌شده و اصلاح‌شده: مسیر `workers.dev` بعد از نصب خودکار روشن می‌شود (قبلاً دستی لازم بود).
- در پلن رایگان، Durable Object باید SQLite باشد → اصلاح شد.
- **وبهوک ربات اصلی تو دست‌نخورده ماند** (بررسی شد: هنوز `rich-post-bot…/telegram/webhook`، بدون خطا).

## صادقانه — سه چیز
1. **سهمیهٔ هوش مصنوعی**: روی حساب هر نفر است. سقف رایگان کلادفلر روزانه محدود است؛ اگر کسی زیاد استفاده کند، باید پلن ۵ دلاری `Workers Paid` را روی حساب خودش بگیرد. (سهمیهٔ حساب تو امروز با اینهمه تست و ساخت تمام شد؛ نیمه‌شب UTC ریست می‌شود.)
2. **گروک** فقط پلن پرداختی قبول می‌کند؛ جمنای و کلاد کار می‌کنند (تو خودت هر سه را داری).
3. **توکن‌ها ذخیره نمی‌شوند**: فقط در همان درخواست استفاده می‌شوند؛ محدودیت ۶ نصب در ساعت برای هر IP. نصب دوباره با همان نام = به‌روزرسانی.
