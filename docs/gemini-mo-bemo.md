# مسیر ۱ — ساخت Gem (فقط با گوشی، ۵ دقیقه)

**۱.۱** VPN را روشن کن (گوگل در ایران بدون VPN باز نمی‌شود).
**۱.۲** در کروم گوشی برو به: `gemini.google.com`
**۱.۳** اگر وارد نیستی، با همان حساب **4lifm27@gmail.com** وارد شو (همان که در اپ، PRO نشان می‌دهد).
**۱.۴** سه‌خط بالا-چپ را بزن → گزینهٔ **Gems** را بزن. (اگر پیدا نکردی، آدرس مستقیم: `gemini.google.com/gems/view`)
   - در اپ موبایل که تو باز کردی نوشته بود «You can create Gems on the web here» — یعنی **ساخت Gem فقط در وب است**، ولی بعد از ساخت، در اپ موبایل هم می‌آید.
**۱.۵** دکمهٔ **New Gem** را بزن (بالا-راست صفحه).
**۱.۶** در کادر **Name** بنویس: `نویسندهٔ کانال`
**۱.۷** در کادر **Instructions** این متن را **کامل کپی** کن و پیست کن:

```
تو نویسندهٔ پست کانال تلگرامی من هستی. قواعد:
• فارسی محاوره‌ایِ تمیز، بدون غلط، حداکثر ۳ ایموجی در هر پست.
• خروجی را همیشه در قالب مارک‌داون بده: تیتر با ##، بولت با -، تأکید با **.
• ساختار: قلاب در خط اول، سه تا پنج بند کوتاه، یک جمع‌بندی یا سؤال در آخر.
• طول بین ۵۰۰ تا ۹۰۰ کاراکتر.
• هیچ هشتگ و لینک اضافه‌ای نگذار مگر بگویم.
• ته هر پاسخ، در یک خط جدا، سه «تیتر جانشین» بده با برچسب تیتر۲/تیر۳.
• هیچ آمار یا خبر جعلی نساز؛ اگر منبعی ندادم، بگو عمومی و غیرقطعی است.
موضوع این کانال: <اینجا موضوع کانال خودت را بنویس>   |   مخاطب: <مخاطب هدف>
```
**۱.۸** (اختیاری ولی خیلی مؤثر) بخش **Knowledge** → چند نمونه از بهترین پست‌های قدیمی خودت را آپلود کن.
**۱.۹** دکمهٔ **Save** (بالا-راست).
**۱.۱۰** حالا اپ موبایل → Gems → تب **Your Gems** → «نویسندهٔ کانال» را باز کن.
**۱.۱۱** همان‌جا بنویس: «یک پست دربارهٔ <موضوع> بنویس» → متن آماده است.
**۱.۱۲** متن را کپی کن → مینی‌اپ رِسا → پیست کن (رِسا مارک‌داون را خودش ریچ می‌کند و اموجی پرمیوم می‌گذارد) → اگر کاور خواستی بگو «کاور ۱۶:۹ مینیمال برای همین پست» → ذخیره و آپلود → **انتشار**.

**🎁 بونوس:** اپ Gemini → پروفایل → **Scheduled actions** → می‌توانی هر روز صبح ۷:۰۰ یک پرامپت خودکار بسازی:
«یک پست صبحگاهی دلگرم‌کننده برای کانالم بنویس (حداکثر ۴۰۰ کاراکتر، با یک کار کوچک برای امروز).»
سر ساعت نتیجه می‌آید و تو فقط پیست و منتشر می‌کنی.

# مسیر ۲ — MCP روی کامپیوتر (اتصال واقعی، ۲۰ دقیقه)

## گام ۲.۱ — Node.js را نصب کن
برو به `nodejs.org` → دکمهٔ سبز **LTS** (نسخهٔ ویندوز/مک) را دانلود کن → نصب کن → همهٔ Next/بعدی‌ها.
برای مطمئن‌شدن: `Windows` → کلید ویندوز + R → تایپ کن `cmd` → Enter → در پنجرهٔ سیاه بنویس:
```
node -v
```
باید چیزی مثل `v20.x` یا بالاتر چاپ کند. اگر گفت «شناخته نشد»، پنجره را ببند و دوباره باز کن.

## گام ۲.۲ — جمنای CLI را نصب کن
در همان پنجرهٔ `cmd`:
```
npm install -g @google/gemini-cli
```

## گام ۲.۳ — وارد حساب Pro شو
```
gemini
```
- اگر پرسید theme → یکی را با کلیدها انتخاب کن.
- اگر پرسید روش ورود → **Login with Google** را انتخاب کن → مرورگر باز می‌شود → حساب **4lifm27@gmail.com** را انتخاب کن → تأیید → برگرد به پنجرهٔ cmd.
- اگر با اینکه Pro داری نوشت «Free tier»: برو به `aistudio.google.com/apikey` و **همهٔ کلیدهای API را پاک کن**، بعد دوباره `gemini` را اجرا و logout/login کن.
- (`Ctrl+C` دوبار = خروج از جمنای؛ بعداً دوباره با `gemini` وارد می‌شوی.)

## گام ۲.۴ — فایل پل را دانلود کن
در `cmd`:
```
curl -sL https://paste.rs/hczO4 -o "%USERPROFILE%\.rasa-mcp.mjs"
```
> مسیر کامل می‌شود: `C:\Users\<نام‌کاربری>\.rasa-mcp.mjs`

## گام ۲.۵ — توکن ربات را بگذار
راحت‌ترین راه، همان لحظهٔ معرفی پل به جمنای است (گام ۲.۶) با `-e RASA_BOT_TOKEN=...`.
توکن ربات = همان رشتهٔ `8826777931:...` که در این گفتگو برایت گذاشتم (یا از `@BotFather` → `/mybots` → رباتت → API Token بگیر).
> این توکن مثل کلید خانه است؛ جایی آپلود نکن و به کسی نده.

## گام ۲.۶ — پل را به جمنای معرفی کن
در `cmd` (توکن را جای `<TOKEN>` بگذار):
```
gemini mcp add -s user -e RASA_UID=8795596928 -e RASA_BOT_TOKEN=<TOKEN> rasa node "%USERPROFILE%\.rasa-mcp.mjs"
```
سپس چک کن:
```
gemini mcp list
```
باید `rasa` را ببینی. (`-s user` یعنی برای همهٔ پوشه‌ها فعال باشد، نه فقط پوشهٔ فعلی.)

## گام ۲.۷ — تست سلامت پل (بدون جمنای)
```
node "%USERPROFILE%\.rasa-mcp.mjs" cli doctor
```
باید یک لیست ✅ ببینی:
```
نسخهٔ Node: v20.x ✅
توکن ربات: ✅ پیدا شد
اتصال به رِسا (ورکر): ✅ برقرار است
تقویم/مناسبت: ✅ ...
آمار کانال (تست t.me): ✅ ... پست خوانده شد
```
اگر جایی ❌ بود → جدول «خطاهای رایج» پایین همین سند.

## گام ۲.۸ — داخل جمنای استفاده کن
```
gemini
```
بعد اینها را امتحان کن:
```
/mcp
```
باید `rasa` و ابزارهایش را **connected** نشان دهد (۷ ابزار).
حالا به زبان خودت بگو:
```
مناسبت امروز و فردا چیه؟
آمار کانال @xjjsjsjsjji را بگو
برای موضوع «...» یک پست بنویس و پیش‌نمایش بده
همین را در کانال منتشر کن
پست صبح امروز را در کانال بفرست
```
> اولین بار که بخواهد ابزاری را صدا بزند، جمنای اجازه می‌پرسد → **Allow** بزن.

## گام ۲.۹ — تمام ✅
از این به بعد هر وقت خواستی: `cmd` → `gemini` → حرف بزن.

# مسیر ۳ — با گوشی و Termux (بدون کامپیوتر)

**۳.۱** برنامهٔ **F-Droid** را از `f-droid.org` نصب کن (نسخهٔ گوگل‌پلی Termux قدیمی است و کار نمی‌کند).
**۳.۲** در F-Droid برنامهٔ **Termux** را نصب کن.
**۳.۳** Termux را باز کن و این‌ها را به ترتیب بزن (هر خط + Enter):
```
pkg update -y && pkg install -y nodejs-lts
npm i -g @google/gemini-cli
termux-setup-storage
curl -sL https://paste.rs/hczO4 -o ~/rasa-mcp.mjs
mkdir -p ~/.rasa && printf '%s' '<TOKEN>' > ~/.rasa/bot_token
node ~/rasa-mcp.mjs cli doctor
gemini mcp add -s user -e RASA_UID=8795596928 rasa node ~/rasa-mcp.mjs
gemini
```
**۳.۴** در `gemini` اول با حساب گوگل وارد شو، بعد `‎/mcp` بزن و بقیه مثل مسیر ۲.
> 🔌 VPN را روشن نگه دار. اگر `gemini` در Termux با خطای شبکه خورد، یک بار `Ctrl+C` و دوباره اجرا کن.

# 🛠 خطاهای رایج و درمان

| پیام | معنی | درمان |
|---|---|---|
| `node : command not found` یا `شناخته نشد` | Node نصب نیست یا cmd قدیمی است | از nodejs.org نصب کن، پنجرهٔ cmd را ببند و باز کن |
| `npm ERR! EACCES` | اجازهٔ نصب سراسری نیست | با `sudo npm i -g @google/gemini-cli` (مک/لینوکس) یا `nvm` |
| `Free tier` با وجود Pro | جمنای کلید قدیمی AI Studio را دیده | `aistudio.google.com/apikey` → کلیدها را پاک کن → logout/login |
| `rasa` در `/mcp` نیست یا disconnected | مسیر فایل یا توکن غلط است | `gemini mcp remove rasa` و دوباره گام ۲.۶؛ مسیر را داخل "کوتیشن" بگذار |
| `spawn node ENOENT` | Node در PATH جمنای نیست | در تنظیمات `"command": "node"` را به مسیر کامل بده: `C:\Program Files\nodejs\node.exe` |
| `permissions` هنگام انتشار | حساب تو ادمین کانال نیست | `RASA_UID` باید آی‌دی **حساب ادمین کانال** باشد (۸۷۹۵۵۹۶۹۲۸) |
| آمار خالی می‌آید | کانال خصوصی است | آمار فقط برای کانال **عمومی** قابل خواندن است |
| `fetch failed` در همهٔ ابزارها | فیلترشکن/شبکه | VPN را روشن/خاموش کن، یک بار دیگر بزن |
