# 🏗 نصب اختصاصی (b45) — هر کس ورکر خودش، سهمیهٔ خودش

> صفحهٔ نصب: **`https://rich-post-bot.4lisarani-1.workers.dev/go`**
> هر کاربری این لینک را باز می‌کند، دو توکن می‌دهد، و ۶۰ ثانیه بعد ورکرِ خودش با لینک MCP اختصاصی آماده است.

## چه چیزی ساخته می‌شود (برای هر نفر)
| مورد | روی حساب چه کسی | چرا مهم است |
|---|---|---|
| ورکر (کد کامل، ۵۹ ابزار) | حساب کلادفلر خودش | سهمیهٔ هوش مصنوعی، درخواست‌ها و داده‌ها همه مال خودش |
| ۳ انبار KV + Durable Object | حساب خودش | پست‌ها، رسانه‌ها، رصدها، تنظیمات |
| ربات تلگرام | توکن خودش از @BotFather | پیوی و کانال خودش |
| لینک MCP | `https://<نام>.<زیردامنه>.workers.dev/api/mcp/<کلید>` | برای وصل‌کردن به جمنای/کلاد/گروک |
| زمان‌بند هر دقیقه | حساب خودش | پست خودکار، RSS، رصد گیت‌هاب |

سهمیهٔ حساب میزبان **هیچ** مصرفی نمی‌شود؛ صفحهٔ نصب و نصب یک‌بار انجام می‌شود و تمام.

## مسیر کاربر (سه قدم)
1. **توکن کلادفلر**: دکمهٔ صفحه، لینک آمادهٔ کلادفلر را باز می‌کند و دسترسی‌های لازم از قبل تیک خورده‌اند:
   `Workers Scripts (Edit)` + `Workers KV Storage (Edit)` — فقط همین دو.
   (فرمت رسمی: `dash.cloudflare.com/profile/api-tokens?permissionGroupKeys=[…]&accountId=*&zoneId=all&name=…`)
2. **توکن ربات** از @BotFather (`/newbot`).
3. **نصب** → ورکر، انبارها، وب‌هوک، زمان‌بند و لینک MCP خودکار ساخته می‌شوند.

بعد از نصب: به ربات خودش `/start` می‌دهد → **مالکیت خودکار ثبت می‌شود** (اولین کسی که در پیوی ربات پیام دهد مالک می‌شود) و راهنمای لینک برایش می‌آید. دستورهای اختصاصی هر ورکر:
- `/mcp` → لینک اتصال (هر وقت گم کرد)
- `/channel @mychannel` → ثبت کانال (بعد ربات را ادمین کانال کند)
- `/help` → راهنمای سریع

## اتصال به هوش مصنوعی‌ها
| سرویس | مسیر |
|---|---|
| جمنای | Settings → Connected Apps → Custom apps for Spark → Add → لینک MCP، Client ID/Secret خالی |
| کلاد | Settings → Connectors → Add custom connector → لینک MCP |
| گروک | grok.com/connectors → New Connector → Custom → لینک MCP (پلن پرداختی) |
| کلاد کد | `claude mcp add --transport http rasa <لینک>` |

## امنیت
- توکن‌ها فقط در همان درخواست استفاده می‌شوند و **ذخیره نمی‌شوند** (نه در KV ما، نه در لاگ).
- محدودیت نرخ: ۶ نصب در ساعت برای هر IP.
- هر ورکر مستأجر کلید MCP خودش را دارد؛ کلید به‌جز صاحبش دست کسی نیست (و با `/mcp` قابل بازیابی است).
- نصب دوباره با همان نام = **به‌روزرسانی** همان ورکر.

## صادقانه
- آزادسازی حساب: سقف رایگان Workers AI روزانه است؛ با استفادهٔ زیاد باید پلن ۵ دلاری Workers Paid فعال شود (روی حساب خود کاربر).
- اگر نام ورکر از قبل باشد، بازنویسی می‌شود (آپدیت).
- اگر توکن کاربر فقط Workers Scripts داشته باشد و KV نداشته باشد، نصب با پیام واضح رد می‌شود (لینک آمادهٔ ما هر دو را دارد).
