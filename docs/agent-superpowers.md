# 🦾 قدرت‌های نسل بعد — نقشهٔ «ایجنت همه‌کاره»

> الان رسا ۹ ابزار دارد (عکس، انتشار، آمار، مناسبت، لینک، نظرسنجی، زمان‌بندی، حذف، کانال).
> این سند فهرست چیزی است که **می‌شود** به آن داد. هر ابزار جدید **خودکار** هم در جمنای ظاهر می‌شود (MCP) و هم در چت/ویس ربات — بدون کار اضافه.

---

## ۱) رسانه — از «یک عکس» تا آلبوم و پست زنده
| ابزار | چه می‌کند | نمونه فرمان |
|---|---|---|
| `publish_media` | هر عکس/ویدیو/فایلی که برای ربات یا جمنای می‌فرستی را با کپشن منتشر می‌کند | «این ویدیو رو با این کپشن بذار تو کانال» |
| `album` | پست آلبومی ۲ تا ۱۰ عکسی (اسلایدشو) | «این ۴ عکس رو یه پست کن» |
| `style_presets` | پریست‌های گرافیکی روی عکس‌ساز: سینمایی، نئون، مینیمال، آبرنگ، سه‌بعدی، رترو | «عکس کاور با استایل نئون بساز» |
| `image_variants` | ۳ نسخهٔ متفاوت از یک ایده تا بهترین را انتخاب کنی | «سه کاور مختلف بساز» |
| `premium_emoji` | متن را با **اموجی پرمیوم** رِسا می‌آراید (موتور خودمان) | «این متن رو با اموجی پرمیوم بذار» |
| `restyle_image` (🛠 در حال تست) | عکس خودت را بازسازی می‌کند (سینمایی/کاریکاتور/رنگ روغن) | «این عکس رو کاریکاتوری کن» |

## ۲) خودکارسازی — «ست کن و فراموش کن»
| ابزار | چه می‌کند | نمونه فرمان |
|---|---|---|
| `rss_to_channel` | از هر منبع خبری RSS (زومیت، دیجیاتو، ایرنا، تسنیم…) خبر تازه را برمی‌دارد، بازنویسی و با عکس پست می‌کند | «هر خبر مهم تکنولوژی رو با لحن خودم پست کن» |
| `recurring` | تکرار دائمی: هر روز/هر هفته ساعت مشخص | «هر شب ۲۲:۳۰ یک پست کوتاه» |
| `daily_auto` | موتور آمادهٔ «صبح کانال + خلاصهٔ روز» (با آمار واقعی و مناسبت) | «روزانه رو روشن کن» |
| `watch` | رصد تغییر: صفحه/نرخ/کلمهٔ کلیدی؛ وقتی شرط رخ داد پست یا خبر بده | «اگه قیمت دلار از ۱۰۰ گذشت، پست بزن» |
| `crosspost` | از یک کانال به کانال دیگر (با بازنویسی و امضای خودت) | «هر چی در کانال X گذاشتم، اینجا هم بذار» |
| `live_post` | پست زندهٔ به‌روزشونده روی یک پیام (نتیجهٔ بازی، نرخ لحظه‌ای) | «نتیجهٔ بازی رو زنده آپدیت کن» |
| `approve_queue` | پست‌ها اول به پیوی تو می‌آیند با دکمهٔ «تأیید / ویرایش / رد» | «تا تأیید نکردم چیزی منتشر نشه» |

## ۳) داده و تحلیل
| ابزار | چه می‌کند | نمونه فرمان |
|---|---|---|
| `market_price` | طلا/دلار/کریپتو را از منابع عمومی می‌گیرد و در پست/کپشن می‌گذارد | «قیمت طلا رو با تحلیل کوتاه بذار» |
| `weekly_report` | گزارش هفتگی: رشد، پست‌های برتر، بهترین ساعت، پیشنهاد هفتهٔ بعد | «گزارش هفتگی بده» |
| `search_archive` | در آرشیو کانال جست‌وجو می‌کند | «آخرین پستم دربارهٔ طلا چی بود؟» |
| `ab_test` | دو تیتر/دو نسخه، بعد از نیم ساعت نتیجه را می‌سنجد | «دو تیتر تست کن، بهترین رو ادامه بده» |
| `suggest` | بر اساس آمار + مناسبت‌ها + آرشیو، ایدهٔ پست می‌دهد | «برای این هفته ۵ ایده بده» |

## ۴) مدیریت کانال و درست‌کردن
| ابزار | چه می‌کند |
|---|---|
| `edit_post` | ویرایش پستی که قبلاً منتشر شده («این جمله را عوض کن») |
| `delete_post` | حذف دقیق هر پست با شماره‌اش (نه فقط آخرین) |
| `pin` / `unpin` | سنجاق و برداشتن سنجاق |
| `moderate` | پاک‌کردن اسپم، بی‌صدا/بن کردن کاربر (ربات ادمین است) |
| `welcome` | پیام خوش‌آمد خودکار برای عضو جدید + قوانین |
| `reminder` | یادآور در پیوی خودت («فردا ۹ صبح یادم بنداز») |

## ۵) زبان و لحن
| ابزار | چه می‌کند | وضعیت |
|---|---|---|
| `translate` | ترجمهٔ متن/پست (انگلیسی↔فارسی و…) | ✅ **تست شد و کار می‌کند** |
| `templates_brand` | ذخیرهٔ «لحن و قالبهات» و اعمال روی همهٔ پست‌های آینده | 🛠 |
| `voice_over` | صدای گویندهٔ **انگلیسی** از متن (TTS)؛ برای فارسی فعلاً نه | ⚠️ محدود |

---

## صادقانه: چیزهایی که فعلاً نه
- **ویدیوسازی خودکار** (Veo): از حساب/API فعلی نمی‌شود. راه واقعی: ویدیو را در اپ جمنای بسازی و برای ربات بفرستی → با `publish_media` منتشر می‌شود. (اگر Gemini/Veo روزی از MCP چیزی بدهد، وصل می‌کنیم.)
- **تحلیل عکس ورودی** (بینایی): مدل بینایی روی این حساب خطا می‌دهد.
- **نوشتن فارسی داخل خودِ تصویر**: مدل‌های تصویری فارسی را بد می‌نویسند؛ راه بهتر: کاور بدون متن + کپشن.
- **تیزر خودکار، تیتر جمنای درون‌کانال**: فعلاً فقط از طریق چت.

## ترتیب پیشنهادی ساخت (بستهٔ ۱ — قدرتمندترین‌ها)
1. `publish_media` + `album` ← ویدیو/عکس خودت را بفرست، منتشر می‌شود (چشمگیرترین)
2. `rss_to_channel` ← خبرخوان خودکار با لحن خودت
3. `daily_auto on/off` + `recurring` ← کانال بدون تو زنده می‌ماند
4. `style_presets` + `premium_emoji` ← کیفیت بصری
5. `translate` + `templates_brand` ← هویت و لحن
6. `edit_post` / `delete_post` / `pin` / `moderate` / `welcome` ← کنترل کامل
7. `watch` + `market_price` ← ایجنت واقعی (واکنش به دنیای بیرون)

> هر کدام ساختی‌شد، در هر دو مسیر (جمنای + چت/ویس ربات) **همان لحظه** ظاهر می‌شود.
