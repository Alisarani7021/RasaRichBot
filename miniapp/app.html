💎 درباره رِسا

رِسا یک استودیوی تولیدی برای ساخت پست‌های تلگرامی با استاندارد ژورنالیه — با معماری additive روی Cloudflare Workers، موتور ۷۳۳ اموجی پرمیوم، دکمه‌های ریچ Bot API 10.3 و مینی‌اپ فارسی.

• بدون وابستگی به AI خارجی — همه‌چیز دستی و قابل کنترل
• انتشار کانال امن: DM → copyMessage (قانون Bot API 9.4)
• فوکوس روی UX فارسی: فونت Vazirmatn، راست‌به‌چپ، نمونه‌محور
