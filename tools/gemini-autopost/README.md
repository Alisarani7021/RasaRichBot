# 🚀 پست خودکار با جمنای — فقط با گوشی (بدون کامپیوتر، بدون نصب)

> **نتیجه:** هر روز صبح ~۷:۰۵، جمنای یک پست تازه می‌نویسد و رِسا خودش آن را در کانال منتشر می‌کند.
> حتی وقتی گوشی‌ات خاموش است (کار روی سرور گوگل اجرا می‌شود). هزینه: **صفر**.

---

## این چطور کار می‌کند؟
```
گوگل اسکریپت (سرور گوگل، هر روز ۷ صبح)
   ↓ ۱. تاریخ شمسی + مناسبت امروز را می‌گیرد
   ↓ ۲. به جمنای می‌گوید: «با لحن کانال من یک پست صبحگاهی بنویس»
   ↓ ۳. متن جمنای را به رِسا می‌دهد (همان مسیر مینی‌اپ)
   ↓ ۴. رِسا مارک‌داون را ریچ می‌کند و در کانال منتشر می‌کند
   ↓ ۵. برای تو پیام «✅ منتشر شد» می‌فرستد
```
> ⚠️ یادت باشد: خودِ **Gem** نمی‌تواند در کانال پست کند (فقط متن می‌نویسد). این اسکریپت است که آن متن را می‌گیرد و به رِسا می‌دهد.

---

## آماده‌سازی (۳ دقیقه) — همه با مرورگر گوشی
1. **VPN روشن** (گوگل است).
2. یک **کلید جمنای رایگان** بگیر:
   - برو `aistudio.google.com/apikey` → با همان حساب **4lifm27@gmail.com** وارد شو.
   - دکمهٔ **Create API key** → کلید را کپی کن (یک رشتهٔ `AIza...`).
   - (رایگان است و برای این کار کافی است.)
3. توکن ربات را داشته باش: `8826777931:...` (همان که در چت تلگرام برایت فرستادم).
4. کانال مقصد باید **عمومی** باشد و ربات در آن **ادمین** باشد.

---

## راه‌اندازی (۵ دقیقه) — قدم‌به‌قدم

### قدم ۱ — پروژهٔ جدید
`script.google.com` را باز کن → دکمهٔ **＋ New project** (پروژه جدید).
> اگر بالا-چپ نوشته *Untitled project*، روی آن بزن و اسمش را بگذار: **رِسا × جمنای**.

### قدم ۲ — کد را پیست کن
تمام متن داخل فایل `Code.gs` را انتخاب و **پاک** کن (Ctrl+A سپس Delete)، و این‌جا **محتوای فایل `Code.gs` که برایت فرستادم** را پیست کن.

### قدم ۳ — پنج خط تنظیمات را پر کن (اول فایل)
```js
BOT_TOKEN: '8826777931:....',        // توکن ربات
RASA_UID: '8795596928',              // همان بماند (ادمین کانال)
GEMINI_KEY: 'AIza...',               // کلید رایگان گام آماده‌سازی
CHANNEL: '@کانال_خودت',              // مثلاً '@xjjsjsjsjji'
TOPIC: 'کانالی فارسی دربارهٔ بازار، طلا و ارز، کریپتو و تکنولوژی',   // موضوع کانالت
```

### قدم ۴ — ذخیره
آیکن 💾 (بالا) را بزن یا Ctrl+S.

### قدم ۵ — اولین تست (همین حالا منتشر می‌شود!)
بالا، منوی کشویی کنار **Debug** → تابع **`postNow`** را انتخاب کن → دکمهٔ **▶ Run**.
- اولین بار پنجرهٔ دسترسی می‌آید: **Review permissions** → حساب خودت → **Advanced** → **Go to … (unsafe)** → **Allow**.
  (این هشدار طبیعی است؛ اسکریپت مال خودت است.)
- تا ۳۰ ثانیه صبر کن → **تلگرام**: هم پست در کانال، هم پیام «✅ منتشر شد» در پیوی خودت.

### قدم ۶ — زمان‌بندی روزانه
همان منو → تابع **`installDailyTrigger`** → **▶ Run**. تمام ✅
از فردا هر روز ~**۷:۰۵ صبح به وقت تهران** پست می‌شود. (اگر می‌خواهی ساعت را عوض کنی: در تابع `installDailyTrigger` عدد `atHour(7)` را با ساعت دلخواه عوض کن و دوباره Run کن.)

### اگر خواستی خاموشش کنی
تابع **`removeTriggers`** → Run. تمام زمان‌بندی‌ها پاک می‌شود.

## چک کردن و خطاها
| کجا | چه کار |
|---|---|
| تب **Executions** (منوی ☰ سمت چپ) | سابقهٔ اجراها؛ هر اجرا را باز کنی پیام لاگ را می‌بینی |
| تابع **`doctor`** → Run | تست سریع: تاریخ، مناسبت، کلید، اتصال رِسا |

| خطا | درمان |
|---|---|
| `حساب ... باید ادمین کانال باشد` | کانال درست است؟ ربات ادمین است؟ `CHANNEL` با @ درست است؟ |
| `کلید جمنای تنظیم نشده` | `GEMINI_KEY` را پر کن (گام آماده‌سازی) |
| پیام جمنای نیامد ولی پست آمد | یعنی جمنای خطا داده و متن جانشین منتشر شده؛ تب Executions را ببین |
| «This app is blocked» هنگام دسترسی | VPN را یک بار خاموش/روشن کن و دوباره Run بزن |
| پست تکراری | خودِ اسکریپت با کلید روز قفل می‌کند؛ اگر دستی `postNow` بزنی به‌عمد دوباره می‌فرستد |

## سؤال‌های معمول
- **هزینه دارد؟** نه. Apps Script رایگان است، کلید Flash جمنای رایگان، رِسا با امضا هم رایگان.
- **اشتراک Pro جمنای به چه کارم می‌آید؟** برای اپ جمنای و Gem (نوشتن دستی، تصویر)؛ برای خودکارِ این اسکریپت همان کلید رایگان کافی است.
- **گوشی‌ام خاموش باشد؟** پست می‌آید؛ کار روی سرور گوگل است.
- **می‌شود دو پست در روز؟** بله — بگو تا نسخهٔ «صبح + شب» را برایت اضافه کنم.
- **تصویر هم بسازد؟** نسخهٔ بعدی می‌تواند کاور هم بسازد و به رِسا بدهد (می‌گوید کدام قالب را می‌خواهی).
